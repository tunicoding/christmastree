# Yılbaşı Atölyesi

Yılbaşı ağacını ayrı bir sayfada süsleyebilirsin. Mevcut `christmas_tree.html` değişmez.

Yerelde denemek için depo kökünde şu komutu çalıştır:

```sh
python -m http.server 8000
```

Ardından tarayıcıda [süsleme sayfasını](http://localhost:8000/christmas_tree/susleme/) aç. Sayfa WebGL 2 destekleyen bir tarayıcı gerektirir. Kamera, hesap veya bir sunucu uygulaması istemez. Süsler ve görünüm ayarları yalnızca tarayıcıda saklanır.

Three.js 0.187.0 bu sayfayla birlikte dağıtılır. Lisans metni [vendor/LICENSE](vendor/LICENSE) dosyasındadır.
